# AWS Well-Architected Framework overview

The AWS Well-Architected Framework helps cloud architects build secure, high-performing, resilient and efficient infrastructure. It is organised into six pillars: Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization and Sustainability.

## How startups should use it
A startup should not try to maximise every pillar on day one. Make trade-offs explicit: an early-stage product usually prioritises cost optimization and operational simplicity, then adds security and reliability controls as users, revenue and compliance obligations grow. Review the architecture regularly using the AWS Well-Architected Tool in the console.

## Design principles shared by all pillars
Stop guessing capacity, test systems at production scale, automate to make experimentation easier, allow architectures to evolve, drive architectures using data, and improve through game days. Infrastructure should be defined as code so it is repeatable and reviewable.
